# Florida State Roleplay

A responsive static website for the Florida State Roleplay ER:LC community.

## Publish with GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Set the branch to **main** and the folder to **/(root)**, then save.
5. Wait for GitHub Pages to publish. The site URL will be:
   https://vihaanchillguy-ui.github.io/florida-state-roleplay/

## Before sharing

- Add your real Discord invite to the joining section in `index.html`.
- Update the department names, recruitment details and rules to match your actual server.
- The current page intentionally does not invent a Discord invite, server code, member count or recruitment status.

The site is plain HTML, CSS and JavaScript. No build tools or paid services are required.
